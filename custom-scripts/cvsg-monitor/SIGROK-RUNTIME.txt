The upstream installer was used only to obtain the runtime. Its installer
registration and Start Menu shortcuts were removed with the official
uninstaller. Protocol decoders, unrelated firmware, bundled Python modules,
and Zadig utilities were intentionally omitted because this monitor requests
raw binary samples and performs CVSG decoding itself.

exact source used to make the monitor directory reproducible and auditable.
